# 💼 Portfolio - Anna Beatriz

Um portfólio pessoal responsivo desenvolvido com **HTML e CSS**, criado com inspiração no curso da **Alura**. O projeto apresenta informações profissionais, links para redes sociais e uma navegação intuitiva.

---

## 🎯 Objetivo

Apresentar de forma moderna e profissional a trajetória e habilidades de uma desenvolvedora Front-end em início de carreira, com foco em design responsivo e boas práticas web.

---

## 📋 Características

✨ **Design Responsivo** - Adaptável para diferentes tamanhos de tela  
🎨 **CSS Bem Estruturado** - Utiliza metodologia BEM para organização  
📱 **Mobile First** - Otimizado para dispositivos móveis  
🔗 **Links Sociais** - Conexões diretas para GitHub e LinkedIn  
♿ **Acessível** - Semântica HTML adequada e boa estrutura

## 🚀 Como Usar

### Visualizar Localmente

1. **Clone ou baixe** este repositório
2. **Extraia** os arquivos em uma pasta
3. **Abra** o arquivo `index.html` em um navegador web

### Ou com um servidor local (opcional)

```bash
# Se tiver Python 3 instalado
python -m http.server 8000

# Se tiver Node.js com http-server
npx http-server
```

Acesse: `http://localhost:8000`
